# МойСклад JSON API 1.2

Этот репозиторий — форк официальной документации МойСклад. Отвечай по ней,
а не по памяти: поля, фильтры и лимиты меняются, а ошибка в имени поля
в API молча даёт пустой результат вместо ошибки.

## Как искать

```bash
python3 .claude/skills/moysklad-api/scripts/docs.py отгрузк печать     # разделы со всеми словами
python3 .claude/skills/moysklad-api/scripts/docs.py --toc documents/_demand.md
python3 .claude/skills/moysklad-api/scripts/docs.py --show documents/_print.md:13
```

Ищи по корню слова («отгрузк», «публикац») или по англ. имени поля (`salePrices`).
Пути — от `source/includes`:

|---|---|
| Авторизация, gzip, фильтры, expand, сортировка, формат дат, коды ответов | `_general.md` |
| Лимиты запросов и автоотключения | `_restrictions.md` |
| Ошибки по кодам | `_errors.md` |
| Документы: отгрузка `_demand.md`, заказ `_customerOrder.md`, счёт `_invoice_out.md`, приёмка `_supply.md` | `documents/` |

## Правила, которые чаще всего ломают интеграции

Каждое подтверждено документацией форка — при сомнении открой указанный файл.

- **Авторизация**: `Authorization: Bearer <token>` (`_general.md`). Токен — секрет: только из
  переменной окружения, никогда в коде, логах, коммитах или чате.
- **Сжатие обязательно**: ровно `Accept-Encoding: gzip`, иначе 415 без тела (`_general.md`).
- **Лимиты** (`_restrictions.md`): 45 запросов за 3 с на аккаунт, 5 параллельных на пользователя,
  20 на аккаунт. При 429 ждать `X-Lognex-Retry-After` мс. 200 одинаковых ошибочных запросов
  в минуту — МойСклад отключает пользователю API, поэтому не повторяй 4xx в цикле.
- **Выборки**: `limit` до 1000, но с `expand` — до 100, вложенность expand до 3.
  Листай `offset`, пока не наберёшь `meta.size`.
- **Деньги в копейках**: `sum`, `salePrices[].value`, `buyPrice.value` делить на 100.
- **Даты** — строки `ГГГГ-ММ-ДД ЧЧ:мм:сс.ммм`, московское время; в фильтрах можно без
  миллисекунд: `filter=updated>=2026-10-25 12:00:00`.
- **id из ссылки**: у вложенных объектов есть только `meta.href` — id это последний сегмент пути.
- **Печать**: `POST /entity/demand/{id}/export/` с `template.meta` и `extension` (pdf, xls, ods, html)
  → 303 и `Location` на файл, который живёт 5 минут; может прийти 202 — опрашивать Location.
  Стандартный шаблон УПД называется «Универсальный передаточный документ» (есть и «(старый)»).
- **Публикация**: `POST /entity/demand/{id}/publication` → `href` вида `https://mskld.ru/…`,
  публичная ссылка без авторизации. Сначала проверь существующие (`GET …/publication`).
- **Вебхуки** (`dictionaries/_webhook.md`, `workbook/_workbook_webhooks.md`): только на платных
  тарифах; ответить 200/204 за 1500 мс, иначе ещё 3 попытки подряд и уведомление теряется;
  повтор приходит с тем же `requestId`; подписи нет — секрет клади в путь URL;
  `diffType=FIELDS` у UPDATE даёт `updatedFields`. Принимай быстро, обрабатывай отдельно,
  и держи страховочный опрос по `updated` — вебхуки не гарантируют доставку.
- **Доп. поля**: значение пишется `PUT` документа с `attributes: [{meta, value}]`, мета поля — из
  `GET /entity/<тип>/metadata/attributes`.

## Внутри apps/shipments-hub

Не пиши HTTP к МойСклад заново — используй `hub/moysklad.py`: там уже лимиты, повторы, gzip,
пагинация, экспорт печатных форм, публикации, доп. поля и вебхуки. Не хватает метода —
добавь его туда же (с ссылкой на раздел документации в docstring) и тест в
`tests/fake_moysklad.py` + `tests/test_moysklad.py`. Новая автоматизация — скил `new-automation`.

Если сеть до api.moysklad.ru закрыта (облачная сессия), не выдумывай ответы API: пиши код
по документации, проверяй на поддельном МойСклад из тестов и скажи, что живой прогон не делался.
