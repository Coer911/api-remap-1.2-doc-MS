# МойСклад JSON API 1.2

`docs/moysklad-api/` — копия официальной документации (коммит — в `SOURCE.txt`).
Отвечай по ней, а не по памяти: лимиты, поля и форматы меняются. Например, в 2026 году
лимит запросов стал считаться на пользователя и получил «вес». А ошибка в имени поля
в фильтре молча даёт пустую выборку.

## Как искать

```bash
python3 .claude/skills/moysklad-api/scripts/docs.py отгрузк печать     # разделы со всеми словами
python3 .claude/skills/moysklad-api/scripts/docs.py --toc documents/_customerOrder.md
python3 .claude/skills/moysklad-api/scripts/docs.py --show _restrictions.md:20
python3 .claude/skills/moysklad-api/scripts/update_docs.py            # подтянуть свежую версию
```

Ищи по корню слова («отгрузк», «публикац») или по англ. имени поля (`salePrices`).

## Что чаще всего ломает интеграции

- Ровно `Accept-Encoding: gzip`, иначе 415 без тела.
- **Лимит за 3 с — на пользователя, с весом запроса** (`_restrictions.md`): для токена
  пользователя 22 с 12.05.2026, 15 с 01.09.2026, 11 с 01.12.2026; токен решения — 45.
  Клиент хаба держит этот график сам (`user_token_budget`). 5 параллельных на пользователя.
  При 429 ждать `X-Lognex-Retry-After` мс. 200 ошибочных запросов в минуту или 100 PUT
  в одну сущность в минуту — МойСклад отключает доступ: не повторяй 4xx в цикле.
- `limit` до 1000, с `expand` — до 100, вложенность expand до 3.
- Деньги в копейках, даты — `ГГГГ-ММ-ДД ЧЧ:мм:сс.ммм` по Москве.
- Статус — `{"state": {"meta": …}}` из `GET /entity/<тип>/metadata` → `states`.
- Доп. поле — `{"attributes": [{"meta": …, "value": …}]}`. Справочник — `value: {"meta": элемента}`,
  элементы пользовательского справочника — `GET /entity/customentity/<id>`; `null` сбрасывает.
- Печать — `POST …/export/` → 303 и `Location` на файл, который живёт 5 минут.
- Вебхуки только на платных тарифах. Ответить 200/204 за 1500 мс, иначе ещё 3 попытки
  и уведомление теряется. Повтор приходит с тем же `requestId`, подписи нет — секрет
  кладут в URL. Поэтому принимай быстро, обрабатывай отдельно и держи опрос по `updated`.

## В этом репозитории

HTTP к МойСклад заново не пиши: используй `hub/moysklad/client.py` (лимиты, повторы,
пагинация, печать, публикации, вебхуки) и `hub/moysklad/fields.py` (статусы и доп. поля
по именам с приведением типов). Не хватает метода — добавь туда, со ссылкой на раздел
документации, и научи этому `tests/fake_moysklad.py`.

Сеть до api.moysklad.ru из облачной сессии обычно закрыта. Пиши по документации,
проверяй на поддельном МойСклад и прямо говори, что живого прогона не было.
